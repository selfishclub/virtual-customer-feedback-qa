# 예시 세션 — 이 톤과 균형을 따른다

> 확장 팩에 **실제로 들어 있는 5명**으로 구성한 I1 패널 인터뷰 예시.
> 판정이 한쪽으로 쏠리지 않고, 모든 발언에 카드 근거가 붙어 있는 형태를 보여준다.

**프로덕트** — 1인 사업자용 견적서·거래명세서 자동화 앱 · 월 9,900원
**타깃** — 30~50대 1인 사업자
**패널** — 확장 팩(3,000명)에서 `--panel --tag '#1인사업자' --age 30-55`

## 인터뷰 발췌

### ⭕ 정성현 (32세, 부동산 감정 전문가, 서울 양천구)

> "아, 이거 지금 저한테 필요한 건데요.
> 제가 지금은 회사 소속으로 감정 나가지만, 언젠가 특수 건축물만 다루는 **작은 사무소를 차리는 게 목표**거든요.
> 그때 되면 감정 보고서랑 청구서를 제가 다 만들어야 하잖아요. 그거 생각만 해도 막막했는데.
>
> 9,900원이면… 저 주 2~3회 초밥 먹는데 그중에 한 끼 값도 안 되네요. 그건 문제가 안 되고요."

| | |
|---|---|
| **판정** | ⭕ 수락 · P1 (지금 바로) |
| **신호** | **A2 내 문제다** — 개업 시 서류 부담이 이미 걱정거리 / **A5 지금 할 이유** — 준비 단계라 미리 익혀둘 시점 |
| **근거** | 카드 "목표": *"자신의 안목이 온전히 반영된 작은 감정 사무소를 운영"* · 카드 "소비": *"주 2~3회 정도 외식… 정갈한 초밥"* |
| **마음이 바뀔 조건** | "감정평가 서식이 안 들어 있으면 못 씁니다. 그건 양식이 정해져 있어서요." |

### 🔺 강윤수 (31세, 모션그래픽 디자이너, 경기 이천)

> "견적서요… 그거 매번 새로 만들어요. 클라이언트마다 항목이 달라서.
> 솔직히 그 시간에 작업을 더 하고 싶죠.
>
> 근데 **월마다 나가는 돈**이라는 게 걸려요. 저는 프로젝트가 몰릴 땐 몰리고, 없을 땐 두 달씩 없거든요.
> 일 없는 달에도 9,900원이 빠져나간다고 생각하면… **주말에 아내랑 가는 갈비집 한 번 참으면 되는 돈이긴 한데**, 그 계산이 자꾸 되더라고요."

| | |
|---|---|
| **판정** | 🔺 조건부 · P2 (마음은 있는데) |
| **신호** | **A2 내 문제다** — 견적서 반복 작업이 실제 통증 / **B3 못 믿음** — 정확히는 *지출 리스크* |
| **근거** | 카드 "종합": *"경제적인 궁핍함"* · 카드 "취미": *"주말이면 아내와 함께 전국의 유명한 돼지갈비 집을 찾아다니며"* |
| **무엇 하나만 풀리면** | **"쓴 만큼만 내는 방식"이 있으면 바로 씁니다.** 건당 결제나 무료 3건 같은 거요. |

> ⚠️ **이 🔺가 이번 세션의 최고 수확이다.** "월 구독 → 종량제 옵션"이 그대로 할 일이 된다.

### 🔺 박승우 (22세, 온라인 쇼핑몰 운영, 서울 강동구)

> "뭐 하는 건지는 바로 알겠어요. 견적서 자동으로 만들어주는 거죠.
>
> 근데 저는 **이미 스프레드시트에 함수 걸어놔서** 주문 들어오면 명세서까지 자동으로 나와요.
> 전공이 정보통신이라 그 정도는 제가 짜거든요.
>
> 나쁘진 않은데… 굳이 옮길 이유를 모르겠네요. 지금 것도 잘 돌아가는데."

| | |
|---|---|
| **판정** | 🔺 조건부 · P3 (나쁘지 않다 정도) |
| **신호** | **A1 바로 알아봄** — 3초 안에 이해 / **B5 안 함** — 할 수 있는데 할 이유가 없음 |
| **근거** | 카드 "일": *"정보통신기술 전공자답게 효율적인 분석 툴을 활용해 업무 시간을 단축"* |
| **무엇 하나만 풀리면** | "제가 쓰는 스프레드시트를 그대로 불러올 수 있으면요. 처음부터 다시 입력하는 건 못 해요." |

> **B5는 기능이 완벽해도 발생한다.** 이미 자기 해결책이 있는 사람에게는 "더 좋은 것"이 아니라
> **"옮기는 비용이 0인 것"** 이어야 움직인다.

### ❌ 노인수 (74세, 부동산 중개사, 충북 청주 흥덕구)

> "계약서를 기계가 만들어준다고요?
>
> 나는 40년을 **오타 하나 안 놓치고** 봐 온 사람이오. 동네 사람들이 나한테 오는 이유가 그거예요.
> 그걸 기계한테 맡기면, 그럼 내가 뭐 하는 사람이 되는 거요.
>
> …그리고 저건 어디를 눌러야 되는 거요? 글씨가 작아서 잘 안 보이는데."

| | |
|---|---|
| **판정** | ❌ 거절 |
| **신호** | **B3 못 믿음** — 자동화가 자기 직업 정체성과 충돌 / **B1 못 찾음** — 글씨 크기·조작 |
| **근거** | 카드 "일": *"계약서의 작은 오타 하나도 그냥 넘기지 않는 지독한 꼼꼼함으로 동네 주민들의 두터운 신뢰를 받는"* · 태그 `#저디지털` `#접근성` `#약관정독` |
| **마음이 바뀔 조건** | "**내가 검토하고 내가 도장 찍는 구조**면 몰라도. 초안만 뽑아주고 최종은 내가 고치는 거면요." |

> **이 거절은 무시하면 안 된다.** "전문성이 곧 자산인 직업"에서는 자동화가 **위협**으로 읽힌다.
> 카피를 *"대신 써드립니다"* 가 아니라 *"초안만 뽑아드립니다"* 로 바꾸면 이 벽이 낮아진다.

## 세션 결론

### 공통으로 켜진 수락 신호
**A2(내 문제다)가 3명**에게 켜졌다. 견적·명세 작업이 실제 통증이라는 건 확인됐다.

### 막힌 지점 — 우선순위
| 순위 | 무엇 | 누가 | 처방 |
|---|---|---|---|
| 1 | **월 구독 부담** (B3) | 강윤수 | **종량제·무료 건수 옵션** ← 🔺를 ⭕로 바꾸는 가장 짧은 길 |
| 2 | **이미 자기 해결책 있음** (B5) | 박승우 | **기존 데이터 가져오기** |
| 3 | **자동화 = 전문성 위협** (B3) | 노인수 | 카피를 "대신"에서 **"초안"** 으로 |

### 아직 확인 못한 것
실제 1인 사업자가 **월 9,900원을 실제로 결제하는지**. 이 데이터에는 소득 필드가 없어 지불 의사는 추정이다.

> 합성 페르소나 5명 대상 정성 조사입니다. 확률 표본이 아니므로 비율로 해석할 수 없으며,

## 이 예시에서 따라야 할 것 5가지

1. **판정 표가 맨 위에.** 읽는 사람이 분포부터 본다
2. **모든 판정에 카드 인용.** 어느 문장에서 나왔는지 밝힌다
3. **비교 대상을 그 사람 생활에서 꺼낸다** — "초밥 한 끼", "갈비집 한 번"
4. **❌에게도 "마음이 바뀔 조건"을 묻는다.** 거절로 끝내면 정보가 반만 남는다
5. **🔺를 가장 크게 다룬다.** 조건부가 그대로 할 일 목록이다
