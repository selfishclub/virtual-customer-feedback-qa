## 3. 대표성 — 이 스킬이 보장하지 않는 것

### ❌ 통계적 대표성이 없다

세 겹으로 없다.

1. **원본이 합성 데이터다.** 공식 통계에 *정렬(aligned)* 됐을 뿐, 실제 인구를 조사한 표본이 아니다.
2. **L1은 사람이 골라 담은 목적 표집이다.** 무작위가 아니다.
3. **L2는 편의 표집에 가깝다.** 스트림을 순차로 훑다가 세그먼트 정원이 차면 멈춘다. 확률 표본이 아니다.

### ❌ 절대 하면 안 되는 것

| 금지 | 왜 |
|---|---|
| **"사용자의 40%가 여기서 이탈합니다"** | 비율 추정 불가. 표본이 확률 표본이 아니다 |
| **"이 가격이면 X% 구매합니다"** | 소득 필드 자체가 없다 |
| **"통계적으로 유의합니다"** | 유의성 검정의 전제가 성립하지 않는다 |
| **A/B 테스트 대체** | 실제 트래픽 실험을 대신할 수 없다 |
| **실제 고객 인터뷰 대체** | 전 단계일 뿐이다 |

### ✅ 이 스킬이 실제로 잘하는 것

| 할 수 있는 것 | 왜 유효한가 |
|---|---|
| **막힘 지점 발견** | 한 명이 막히면 그 지점은 실재한다. 몇 %인지 모를 뿐이다 |
| **놓친 관점 노출** | 나와 다른 조건의 사람이 무엇을 먼저 보는지 |
| **용어·카피 오해 탐지** | 오해는 한 건만 나와도 증거다 |
| **거절 이유의 종류 수집** | 종류(what)는 잡힌다. 빈도(how many)는 못 잡는다 |
| **타깃 경계 탐색** | 경계 사용자가 어디서 갈리는지 |
| **실제 인터뷰 전 질문 설계** | 무엇을 물어야 할지가 좁혀진다 |

> **한 줄 요약** — 이 스킬은 **"몇 %인가"에 답하지 않는다. "무엇을 놓쳤는가"에 답한다.**
> 정량 판단이 필요하면 실제 사용자 데이터를 봐야 한다.

## 4. 표본 크기를 얼마로 잡을 것인가

정성 조사에서 새로운 발견이 멈추는 지점(포화)은 보통 소수 인원에서 온다. 그래서 **패널은 5명이면 충분하고, 풀은 클수록 좋다.**

| 무엇 | 권장 | 이유 |
|---|---|---|
| **한 세션 패널** | **5명** (핵심2·경계2·비사용자1) | 더 늘려도 새 발견보다 중복이 빨리 는다 |
| **QA 패널** | **3명** | 단계별 추적이라 인원이 많으면 리포트가 무너진다 |
| **후보 풀(L2)** | **1,500~5,000명** | 조건에 맞는 5명을 뽑을 수 있으면 충분하다 |

풀을 키우는 건 **정확도가 아니라 적중률**을 위해서다. "부산 40대 필라테스 강사"가 실제로 걸리느냐의 문제다.

## 5. 확장 팩 표집 방식 선택

`build_extended_pack.py --balance` 로 정한다.

| 값 | 방식 | 언제 |
|---|---|---|
| **`even`** (기본) | 5개 세그먼트에 균등 배분 | **각 집단을 고르게 만나고 싶을 때.** 대부분 이쪽 |
| `natural` | 정원 없이 원본 순서대로 수집 | **원 데이터 분포에 가깝게** 두고 싶을 때 |
| `custom` | `--weights A=0.2,C=0.4,...` | 특정 집단을 두껍게 (예: 1인 사업자 타깃) |

> `even`은 실제 인구 분포와 다르다. 그래서 더더욱 **비율 해석을 하면 안 된다.**
> 대신 소수 집단(시니어·자영업)을 만날 확률이 올라가 blind spot 발굴에 유리하다.

또한 **같은 직업이 세그먼트 정원의 5%를 넘지 못하도록** 상한을 둔다. 한 직업이 팩을 잠식하는 것을 막는다.

## 6. 재현성

| 장치 | 무엇 |
|---|---|
| `--seed` | 같은 씨앗 + 같은 조건 = 같은 결과 |
| **패널 스냅샷** | 한 번 뽑은 5명을 저장해 재사용 |

**수정 전후를 비교할 때는 반드시 같은 패널을 쓴다.** 사람이 바뀌면 카피가 통한 건지 사람이 달라진 건지 구분할 수 없다.
